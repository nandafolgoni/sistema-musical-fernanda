## 🎵 Visão Geral

O **Sistema Musical** é uma aplicação web desenvolvida para permitir a administração de acervos musicais, incluindo o cadastro de artistas, inserção de músicas com letras e links do YouTube, e consulta através de uma biblioteca com filtros de busca.
